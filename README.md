# MarkerSync for Cavalry
Sync time markers to an array automagically in Cavalry, the 2D animation software.

### [Download latest version →](https://github.com/sammularczyk/cavalry-markersync/releases/latest)

## Demo

https://github.com/user-attachments/assets/a529a4bd-5a77-4aaa-9235-618f95a6b5d4


## Usage
1. Open MarkerSync
2. Press Link Array
3. Add, move and remove markers to your hearts content

## Why?
This is perfect for time offseting duplicators. For example, lets say you want a duplicator to delay in a non-linear fashion. You could use a stagger, or use MarkerSync to trigger them precisely.

Use with Timeline Counters for extra control.

I made this so I could trigger Forge elements and apply a duplicator to Forge so I could scale and animate the elements over their lifetime!

## Installation
Copy `MarkerSync.js` to your Cavalry scripts folder.
